# Shoebox gallery

Public reference gallery: https://workcr.github.io/shoebox-gallery/

This repository contains the published gallery only, not raw account exports, credentials, browser sessions, or the private project history. Save timestamps and playlist names are omitted.

Images are loaded from their original hosts and may become unavailable. Linked content remains the property of its respective creators. Vimeo is not included because its export has not been provided.

This is a snapshot; future saves are not synchronized automatically.
